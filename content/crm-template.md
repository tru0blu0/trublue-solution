## Column Definitions

**Date:** First contact date (YYYY-MM-DD format)
**Source:** Where did this lead come from? Options: Referral, LinkedIn, Website, Chamber Event, Cold Outreach, Past Client, Other
**Company:** Company name
**Contact Name:** Full name of primary contact
**Contact Email:** Email address
**Contact Phone:** Phone number (optional)
**Industry:** Logistics, Restaurant, Legal, Manufacturing, Professional Services, Other
**Stage:** Prospecting → Qualified → Proposal Sent → Negotiation → Closed Won / Closed Lost
**Engagement Type:** Diagnostic, Systems Build, Fractional COO, Other
**Est. Value:** Estimated revenue ($)
**Notes:** Any relevant context — who referred them, what problem they have, key details
**Next Step:** What action needs to happen next?
**Follow-up Date:** When to follow up if no response (YYYY-MM-DD)

## Monthly Review Questions
1. Which source generated the most qualified leads? (double down)
2. Which source generated leads that didn't convert? (fix or drop)
3. What's the average time from Prospect → Closed Won?
4. What's the conversion rate per stage?
5. What's the most common objection at the Proposal Sent stage?
6. Which industry converts best?
7. Total pipeline value vs. closed revenue this month?

## Setup Instructions
1. Create new Google Sheet: sheets.google.com → Blank
2. Copy the header row above into Row 1
3. Freeze Row 1 (View → Freeze → 1 row)
4. Add data validation for Stage and Source columns (Data → Data validation → Dropdown)
5. Add conditional formatting: "Closed Won" = green, "Closed Lost" = red
6. Bookmark the sheet — review every Friday
